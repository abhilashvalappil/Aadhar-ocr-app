# 🪪 Aadhar OCR

A full-stack MERN application that extracts and processes text data from Aadhar card images using Optical Character Recognition (OCR).

## 🚀 Features
- Upload an Aadhar card image (JPG, PNG)
- Extract details like:
  - Name  
  - Date of Birth  
  - Aadhar Number  
  - Address  
  - Gender
- Validate and format extracted data
- Store records securely in MongoDB
- RESTful API for OCR processing
- Clean and responsive frontend built with React

---

## 🧠 Tech Stack
**Frontend:** React, TailwindCSS / Material-UI  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**OCR Engine:** Google Vision API
